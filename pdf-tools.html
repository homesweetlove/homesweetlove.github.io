PDF 도구

변환과 병합은 브라우저 안에서 진행되며 파일이 서버로 업로드되지 않습니다.

01 / CONVERT

PPTX → PDF

슬라이드의 기본 텍스트, 이미지 및 배경을 PDF로 만듭니다. 복잡한 차트, 도형, 표, 특수 글꼴과 애니메이션은 원본과 다를 수 있습니다.

02 / MERGE

PDF 합치기

PDF 여러 개를 추가하고 ↑ ↓ 버튼으로 순서를 조정한 뒤 하나의 PDF로 저장하세요. 암호로 보호된 PDF는 지원하지 않습니다.

    PPTX의 복잡한 레이아웃을 원본과 똑같이 보존해야 하는 경우 PowerPoint 또는 LibreOffice의 PDF 내보내기를 사용하세요. 이 도구는 기본적인 슬라이드를 빠르게 변환하는 간편 모드입니다. 처리 중에는 탭을 닫지 마세요.
