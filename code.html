수업에서 작성한 HTML 코드를 모아두는 페이지입니다.

실습 1 - 자기 소개서 작성

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>자기 소개서 작성</title>
</head>
<body>

<form>
    <fieldset>
        <h3>자기 소개서 작성</h3>
        <hr>

        이름:
        <input type="text"><br>

        암호:
        <input type="password"><br>

        자소서:
        <textarea rows="5" cols="20" placeholder="이곳에 자기소개서 작성"></textarea>

        <hr>

        나라:
        <input type="text" list="country">
        <datalist id="country">
            <option value="가나">
            <option value="스위스">
            <option value="브라질">
        </datalist>
    </fieldset>
</form>

</body>
</html>
